## LinkedIn

This week, I continued my HealthConnect Rwanda project as part of the AnalystLab Africa Data Science track.

I reviewed the admission prediction model developed in Week 6 and tested whether changes to the features and modeling approach could improve its performance. I checked for target leakage, used a chronological train-validation-test split, compared Logistic Regression with a Random Forest, and examined the model’s false positives and false negatives.

The results were a useful reality check: the refined model did not show a reliable improvement over a simple reference model. The data also do not include an attendance or no-show outcome, so they cannot support a missed-appointment prediction yet.

I documented these limitations and exchanged findings with a Data Analytics intern, including the missing no-show field and questions about which features the data can support. The next step is to review the target and feature list together and retest any changes against a later time period.

This work reminded me that building a model is only one part of data science. Checking whether the data and results support the intended use matters just as much.
